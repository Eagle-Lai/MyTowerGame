# 《自由人塔防》全界面 UI 重设计

成果位置：**D:/FishTestGame/Docs/UI_Redesign/2026-10-26**

从 [index.html](index.html) 开始审阅，或直接打开逐页 PNG。此目录只保存设计交付物，不是 Unity 可运行资源。

## 交付组成

- screens/png/：85 张 1920×1080 简体中文基础页面与状态；screens/svg/ 为一一对应的独立可编辑 SVG。
- localization/png/ 与 localization/svg/：同一批基础稿的完整繁体中文与英文版本，共 170 张，各自独立。
- wireframes/png/ 与 wireframes/svg/：85 张逐页线框结构稿；文字、区域与分状态对应高保真稿。
- adaptations/：关卡选择、战前简报、选中塔 HUD、胜利结算的 1024×768、1280×720、2340×1080、2560×1080 适配。
- system/：视觉系统、组件状态、双方向探索、安全区、大字档、全流程导航与品牌提案。
- specs/：完整页面清单、逐页 UX 说明、交互规格、三语文案、证据、验收和审阅说明。
- assets/：设计包内部使用的参考炮塔、敌人形象副本及新生成的概念主视觉。

## 设计宣言

「战术铸舱 / Tactical Forge」把界面组织成可判断、可操作的防线指挥空间：深空底和哑光金属延续原有深色科技身份，青色只标示当前交互与选中，金色负责荣誉，红色负责危险，三种炮塔继续使用玩家熟悉的形象。品牌页拥有有深度的战场主视觉；战斗页把空间交还棋盘；塔操作以地图定位与属性比较并列；结算以一次荣誉表达加关键原因取代密集文字。新盾塔标记是本轮提案，品牌名保持《自由人塔防》。

## 数据和范围边界

本次没有读取源代码、存档或数值配置，也没有操作 Unity 编辑器。关卡、波次和评级容量应来自当前有效配置；三类炮塔与无声版本为本轮历史设计范围，旧截图中的数值不作为配置依据。

**所有页面是条件分支设计，不是玩家实况。** 金币、生命、伤害、间隔、射程、返还金额、解锁、实际评级与用时没有实时数据，因此用“—”而非历史测试数字。五星轮廓仅展示组件容量，不表示实际获得星数。最终验收中的“真实数据与真机复核”未通过，不宣称完成了设备测试。

主菜单、开屏、加载、热更新、图鉴等按文档“规划界面”交付，完整标注见 specs/page-inventory.md。部分后续截图已证明战前详情存在，但未现场核验运行版本。热更新整链只在产品实际启用资源服务时适用。

## 推荐审阅顺序

1. system/03_directions.png 与 system/01_design-system.png。
2. 主菜单 → 全量关卡导航 → 战前简报 → 备战 → 战斗 → 选中塔 → 出售确认。
3. 胜利、失败、低星、保存中、保存失败、保存成功、新纪录与末关完成。
4. 1024×768 与超宽适配，再看英文长文案与繁体中文。
5. specs/acceptance.md 中的通过项、待修正项及验证边界。

所有 SVG 均内嵌所用图片，便于单独导入设计工具；文字使用本机 Microsoft YaHei / Arial，跨机导入需准备相同或等效授权字体。文件不是已连接 Figma 画布。PNG 可以直接查看。报告和审阅页不需要联网。

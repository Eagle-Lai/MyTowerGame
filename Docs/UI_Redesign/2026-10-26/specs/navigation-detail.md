# 导航与返回详细说明

补充system/05_navigation.png的总览。所有页面都是设计稿，图册链接不执行游戏动作。

| 来源 | 输入或结果 | 目标 | 返回与限制 |
|---|---|---|---|
| 开屏 | 启动完成 | 加载/条件适用的资源准备 | 无可信进度不显示百分比 |
| 资源准备 | 检查→下载→校验→完成 | 主菜单 | 暂停↔继续；失败→重试；返回启动来源 |
| 加载 | 成功 | 原请求目标页 | 失败→重试或选关，保留进度 |
| 主菜单 | 开始/选关 | 全量关卡导航 | 返回主菜单 |
| 主菜单 | 有效继续 | 保存关卡简报/加载 | 无有效检查点不出现继续 |
| 主菜单 | 图鉴/设置/退出 | 对应页面/退出确认 | 取消回主菜单 |
| 关卡导航 | 选关/简报 | 对应战前简报 | 保留选中位置；锁定只展示原因 |
| 战前简报 | 挑战/继续 | 加载→备战/已保存波次 | 重开进确认，返回选关 |
| 简报 | 玩法说明 | 图示步骤 | 返回简报；开始备战依实际可用入口 |
| 备战/波间 | 点塔型后点合法地块 | 建造成功 | 非法/占用/不足原位提示；取消回战场 |
| 备战/波间 | 拖至合法地块 | 同一建造结果 | 双路径运行能力未核验 |
| 备战/波间 | 开始/下一波 | 战斗 | 迎战中不能跳波 |
| 战场 | 点已建塔 | 选中塔/HUD→完整塔操作 | 空地或关闭回战场；范围可隐藏 |
| 塔操作 | 升级 | 原位刷新属性 | 不足/满级不提交；失败保留原塔 |
| 塔操作 | 出售 | 确认→处理→战场 | 取消回同一塔；失败保留塔和金币 |
| 战场 | 暂停 | 暂停页 | 继续回原局；设置关闭仍暂停 |
| 暂停 | 重开/选关 | 具体动作确认 | 取消回暂停；清除失败中止跳转 |
| 设置 | 切换语言 | 同页新语言 | 关闭回原来源 |
| 设置 | 重置 | 危险确认→处理→结果 | 失败返回设置/重试，不误报成功 |
| 战斗 | 胜利 | 结果→保存中 | 保留结果，不提前发布新纪录 |
| 保存中 | 成功 | 已保存/真实新纪录 | 恢复下一关、重玩、返回 |
| 保存中 | 失败 | 保存失败 | 重试→保存中；说明→结算/重试 |
| 已保存结果 | 下一关 | 下一关简报 | 非末关且保存成功才可用 |
| 已保存结果 | 重玩/返回 | 本关简报/选关 | 风险动作经对应确认 |
| 失败 | 重试/返回 | 本关简报/选关 | 不虚构奖励 |
| 末关完成 | 返回/重玩 | 选关/末关简报 | 无下一关按钮 |
| 图鉴 | 切换/比较/详情 | 对应条目或比较页 | 返回图鉴/主菜单来源 |

系统返回先关闭最上层信息或预览，再执行页面安全返回。提交后不可中止的处理层不能用取消伪装撤销。长期无响应应进入明确错误恢复，不无期限锁住玩家。

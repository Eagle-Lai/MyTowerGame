# 视觉设计系统：战术铸舱

## 两种方向与选择

A 战术铸舱：深空哑光、结构切角、少量金属深度、青色定向交互。与既有炮塔和方格战场最接近；减少全屏持续发光，主操作、信息与战场形成不同权重。选用 A。

B 夜航光谱：薄膜叠层、冷色光迹、轻量光学空间。启动与加载有辨识度，但密集敌群背景下对比更不稳定，且易偏离原机械炮塔气质。本轮只保留方向探索稿，不混用组件。

## 字体

- 品牌标题：100px / 750；页面标题：46–52px / 700；分区标题：32–36px / 600。
- 核心数值：44px / 650；按钮与正文：28–32px / 500–600；辅助：24–26px。
- 1024×768适配正文20–26px，层级重新布局，不把全屏成比例缩小。大字示例正文与按钮36px。
- Microsoft YaHei 负责中英文可读性，Arial为后备。数字应为表格宽度，金币、生命、波次的数值与单位紧邻。
- 英文长按钮保留字号，先改短文案、扩大容器或分两行，不统一缩小。语言名保留各语言自己的名称，避免在小宽度内挤入“Traditional Chinese”。

## 几何与层级

基准1920×1080；内容边距64–80；间距8/16/24/32/48/64；机械切角16；描边1.5–2px；只有当前选中和关键操作使用高对比边缘。大背景不围满等权亮框。主要按钮88–104px高，次级76–88px高。

实际触控按设备dp目标≥48×48，间隔≥8dp复核。设计像素不是dp测量；当前未收集真实密度，因此不宣称热区已经真机通过。

## 符号

速射塔：既有红铜炮身，交互青色角色线；火力塔：既有深色重炮，橙色类型线；减速塔：既有蓝色水晶，冰色类型线。相同塔型在HUD、图鉴、操作面板、出售确认中保持一致，等级用明确数字。

资源使用六边金币、基地使用心形、入口使用方向箭头、终点使用目标环、锁定使用锁、危险使用三角叹号、成功使用勾。图标以2.4px基础描边绘制，默认与文字并列。

## 控件状态

| 状态 | 表达 |
|---|---|
| 正常 | 哑光工具面、可读文字、边线 |
| 悬停/焦点 | 明亮外焦点线、方向标，不只改色 |
| 按下 | 内容下压2px、底色加深，90ms完成 |
| 选中 | 类型色条+勾+“已选中” |
| 禁用 | 仍保留可读标签；同时说明金币不足、满级或处理中 |
| 错误 | 警告符号+明确原因+可执行重试或取消 |
| 成功 | 勾+结果文案；仅结果确定后出现 |

## 动效节奏

按压90ms；局部提示140ms出现/140ms退出；面板180ms；胜利荣誉320ms；进度只按真实反馈更新。成功提示停留约1.6s，普通警告2.8s，阻塞错误保持到玩家处理。避免无操作时持续扫描、跳数、抖动和全屏发光。可选触觉只作为未来产品确认项，本轮没有新增设置开关。

# 比例、语言与安全区

## 比例策略

| 比例 | 检查稿 | 重新编排 |
|---|---|---|
| 1920×1080 | screens/ | 页面主构图，战场上资源条/下塔栏位置稳定 |
| 1280×720 | adaptations/ 四类页面 | 低高度分栏；简报减小地图高度但不遗漏主动作 |
| 1024×768 | adaptations/ 四类页面 | 选关5列变4列；简报纵排；HUD属性横条与底部建造不重叠；结算采用紧凑统计 |
| 2340×1080 | adaptations/ 四类页面 | 预览与属性利用侧边空间，棋盘居中保留入口基地 |
| 2560×1080 | adaptations/ 四类页面 | 扩宽操作间距与地图观察，不把正文字号放大到占满空间 |

战场逻辑没有因为屏宽改变；地图仅做显示布局示意，不是当前运行时地图认证。攻击范围圆为构图示意，不表达实际射程。

## 安全区与大字

system/04_safearea.png 展示侧边与手势区压力；additional safe稿按示例左右96px、上下24px/36px作为设计压力值。各 Insets 需要在真实目标机收集后复核。不能把安全区框理解为真机测量结果。

主动作、返回、取消与战场入口基地都应退入安全区。比例变化优先移动工具栏或改变列数，不把整套UI简单缩小。

大字档维持正文36px与关键操作36px，布局拆行而非缩字；本轮附大字阅读代表画面，不宣称运行版本已有字号设置。

## 三语言

全部85个基础页面/状态均给出简体、繁体、英文独立SVG/PNG。English按玩家操作语义翻译，不直译内部术语。语言名保留“简体中文 / 繁體中文 / English”，以便切换回来。

英文长按钮按原字号拆两行；中文/英文均执行字体几何边界扫描。扫描只证明所检查文本未越出画布与特定居中按钮；它不等同所有相邻控件碰撞、真机字号、系统字体或其他语言校对通过。

繁体采用字形转换后对核心词人工覆写；地区用语仍建议由目标市场编辑复核，例如“储存/保存/存档”的统一。正式国际化验收应使用实际语言配置完整替换数据插值。

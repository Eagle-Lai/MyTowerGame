# 审阅说明

## 三项最重要的体验变化

1. **选关从翻页找目标改为全量导航与当前简报并列。** 全部有效关卡可浏览，当前条目被定位；玩家在决定挑战前先看地图、初始资源与条件，减少只看关卡号盲进。
2. **战场从中央弹板改为稳定HUD与关联侧栏。** 资源、波次、暂停、塔栏和下一波保持位置；选中塔有地图标记，范围能关闭；价格不足与落点非法各自说明原因，不用通用错误盖住棋盘。
3. **结算从信息堆叠改为结果、关键原因与保存事实。** 五星只做一次荣誉表达；未保存时不冒充新纪录；末关给有效返回/重玩，失败明确下一步。

## 需要产品确认的少量假设

英文品牌名、新盾塔标记、3级上限、双输入建造在当前版本的真实可用性、倍速档位，以及保存失败长期无响应时的恢复规则。见evidence-and-assumptions.md。

## 当前已完成

完整范围清单、逐页独立PNG/SVG、每状态线框、两方向探索、视觉令牌与组件状态、导航图、三语基础稿、四类页面四种比例适配、交互规格、审阅索引和验收表。关键页面已按实际导出图检查并修正。

# 交互规格

| 用户操作 | 结果与视觉反馈 | 不可用/风险 | 取消/返回 |
|---|---|---|---|
| 点开始游戏 | 打开选关，首要动作变为当前关卡简报 | 资料读取失败时提供重试 | 返回主菜单 |
| 点继续游戏 | 显示有效检查点对应关卡并继续已保存波次 | 无有效快照则不显示继续按钮 | 返回不更改存档 |
| 点关卡 | 左侧定位选中，右侧更新预览与历史成绩 | 锁定配锁图形+文字，不假装可开局 | 返回主菜单 |
| 浏览全部有效关卡 | 网格覆盖全部有效关卡；窄比例重排4列；锁定不影响浏览地图 | 解锁规则由当前数据解释 | 保留浏览位置 |
| 看战前简报 | 地图、波数、初始资源优先；敌人资料缺失解释原因 | 五星条件从当前关卡读取，不能用旧标准推断 | 返回所选条目 |
| 点选塔再点地块 | 显示塔影、范围和当前位置是否合法 | 堵路、占用、入口/基地、金币不足各自解释，不扣款 | 再点已选塔或取消建造/系统返回 |
| 拖塔到地块 | 同一套合法性预览；松开合法位置建造 | 非法位置松开保持原金币并显示原因 | 拖出棋盘或点取消 |
| 点已建塔 | 所选塔勾边/范围，侧栏显示身份等级、属性与升级前后 | 侧栏不遮所选塔、入口和基地 | 关闭塔面板，或再次点空地 |
| 点升级 | 显示真实价格与变化，成功后原位更新 | 不足显示差额；满级显示“最高等级”；处理未完成不重复触发 | 未提交前可关闭；提交中只等待结果 |
| 点显示/隐藏范围 | 只切换范围叠层；选中塔仍高亮 | 无额外经济效果 | 再点即可切回 |
| 点出售 | 展示同一塔型/等级、真实返还、不可逆后果 | 返还未知不能确认提交 | 保留炮塔回塔面板 |
| 点暂停 | 暂停层和“战斗暂停”说明；继续是唯一首要动作 | 不自动进入暂停状态；这里仅为设计分支 | 继续回原战场 |
| 在暂停层点设置 | 打开设置后返回原暂停来源 | 不隐式恢复战斗 | 关闭回暂停 |
| 切换语言 | 当前语言有勾与选中底，不只用颜色 | 保留位置与未提交确认状态 | 返回原来源 |
| 点重置存档 | 二次确认列出关卡进度、评级与局内存档将清除 | 默认安全项“保留存档”；删除明确动词，失败不显示成功 | 保留/返回设置 |
| 点重开 | 描述本局布防与未保存结果将清除 | 清除失败中止重开并重试 | 继续战斗 |
| 点返回选关 | 说明未完成波次回已保存检查点 | 保存/清除失败则停留原处 | 取消回原来源 |
| 点下一波 | 仅波间/备战可用，按钮位置稳定 | 战斗中显示“迎战中”，不伪装可跳过当前波 | 通过暂停停止推进 |
| 点倍速 | 文案始终显示当前档 | 本轮只示×1；可用档位待产品核验 | 不新增未知速度规则 |
| 获得胜利 | 先本次结果，再关键原因；后台进入保存 | 保存未成功不发布新纪录，不允许进入下一关 | 保存完成后可重玩/返回 |
| 保存失败重试 | 原结果保留，明确“成绩尚未保存”+重试 | 不给下一关伪成功，不清零成绩 | 保存说明后留在结算或重试，不提供未经核验的丢弃入口 |
| 失败结算 | “防线失守”+图形和原因；重试为首要动作 | 不假设获得奖励/星级 | 返回关卡选择 |
| 末关完成 | 文字说明“没有下一关” | 不创建“最后一关”假按钮 | 有效去向为返回或重玩末关 |
| 更新暂停/继续/失败 | 检查、下载、校验与完成阶段互斥，原因可读 | 无真实已下载量不显示虚构百分比 | 依当前阶段提供暂停、继续、重试、返回 |

## 层级、提示与误操作

- 返回规律：浏览页左上返回；关闭次级信息回来源；模态取消回来源；系统返回与可见取消一致。
- 模态底层仍可看出场景，但不接受底层触摸；高风险动作不通过点遮罩、返回或超时自动提交。
- 出售、重置、离开、重开使用明确动词；不使用只有“OK/确定”的按钮。
- 金币不足提示贴近价格，地块非法提示贴近预览位置；长期错误不以短暂Toast代替。底部信息条是同时可读的兜底。
- 轻反馈不遮路线入口、基地、敌群或所选塔；阻塞保存错误可以覆盖结算操作，但保留结果可见。
- 启动、加载与更新的完成时刻以事实事件为准，百分比缺失则不制造加载条；没有真实进度只显示阶段与不确定等待。

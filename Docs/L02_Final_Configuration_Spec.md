## 三、EnemyData.xlsx 配置

### 3.1 转换规则

对L01的每个敌人变体(106个):

1. **enemyId**: `5000001` → `6000001` (所有ID +1000000)
2. **hp**: 原值 × **1.05**
3. **goldDrop**: 原值 × **1.05** (保持金币/HP比例)
4. **其他字段**: moveSpeed, armor, damageToPlayer, bodyRadius, isFlying, type, resName等保持不变
5. **desc**: 追加 `" | L02-scale-20261102: hp×1.05, gold×1.05, count×1.5"`

## 四、EnemyList.xlsx 配置

### 4.1 转换规则

对L01的每个出怪列表(25个):

1. **id**: +2000偏移 (1→2001, 401→2401)
2. **EnemyIndexs**: 
   - 每个敌人ID +1000000
   - **怪物数量 ×1.5** (重复ID以增加数量)
3. **enemyInterval**: 保持不变 (维持出怪节奏)

### 4.2 示例转换

**L01 W1 出怪列表** (假设有31只):
```
id: 1
EnemyIndexs: "5000001,5000001,5000001,..." (31个ID)
enemyInterval: 280
```

**L02 W1 出怪列表** (增加到47只):
```
id: 2001
EnemyIndexs: "6000001,6000001,6000001,..." (47个ID = 31×1.5)
enemyInterval: 280
```

### 4.3 具体实施方法

对于每波的EnemyIndexs字符串:
1. 解析为ID列表: `[5000001, 5000001, 5000002, ...]`
2. 转换ID: 每个+1000000
3. **扩展数量**: 
   - 如果原有31个 → 复制到47个 (31×1.5=46.5≈47)
   - 如果原有726个 → 复制到1089个 (726×1.5=1089)
4. 重新组合为逗号分隔字符串

- L01击杀总金币≈300

```

```

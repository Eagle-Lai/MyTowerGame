## 三、通关策略建议

### 3.1 地图特征
- **地图大小**: 16×9 = 144格
- **可建造格**: 142格
- **路径长度**: 约18.4格（估算）

### 3.2 推荐塔型配置
基于2498金总经济，推荐建造：
- **普通塔**: 8-10座（全能型，可打空中）
- **火力塔**: 4-6座（高DPS，地面AOE）
- **减速塔**: 2-3座（控制型，光环减速）

### 3.3 阶段性策略

**W1-4 (起步期)**
- 目标金币: 100(初始) + 52×4 = 308金
- 建议: 建造3座普通塔1级，覆盖关键路径

**W5 (第一压力波，飞行怪登场)**
- 目标金币: 308 + 122 = 430金
- 建议: 升级1-2座普通塔到2级，准备应对飞行单位

**W6-9**
- 目标金币: 430 + 63×4 = 682金
- 建议: 增建2座火力塔，开始形成火力网

**W10 (第二压力波)**
- 目标金币: 682 + 127 = 809金
- 建议: 升级关键普通塔到3级，增建减速塔

**W11-14**
- 目标金币: 809 + 66×4 = 1073金
- 建议: 均衡升级火力塔和普通塔

**W15 (第三压力波)**
- 目标金币: 1073 + 131 = 1204金
- 建议: 完成核心塔阵升级，增加补充塔位

**W16-19**
- 目标金币: 1204 + 68×4 = 1476金
- 建议: 填补防御漏洞，准备终局

**W20 (第四压力波)**
- 目标金币: 1476 + 135 = 1611金
- 建议: 全力强化火力，考虑卖掉低效塔重建

**W21-25 (终局)**
- 目标金币: 1611 + 71×4 + 103 = 1998金 (含击杀金)
- W25有Elite单位，需要最强火力覆盖

## 五、预期结果

### 5.1 成功标准
- ✅ 零漏怪通关（剩余生命=12）
- ✅ 金币使用合理（剩余<200金）
- ✅ 所有25波完成
- ✅ 无卡顿或Bug

### 5.2 可能的问题

| 问题 | 可能原因 | 调整方案 |
|------|---------|---------|
| 经济不足 | 波次奖励太低 | 提高奖励金币 |
| 漏怪过多 | 怪物太强/太快 | 降低HP或减少数量 |
| 太简单 | 怪物太弱 | 提高HP或增加数量 |
| 飞行怪难以应对 | 飞行怪HP过高 | 单独调整空中单位HP |

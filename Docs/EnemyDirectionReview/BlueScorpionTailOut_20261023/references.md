# 外弯参考

本轮按用户“向外弯曲，不向身体内侧弯曲”的要求制作尾梢向身体外侧展开的游戏姿态；参考图用于尾根与腹部的连接及轮廓关系，不将某一种照片姿态当作唯一标准，也不复制网络图片到生产图集。

- [VAPAGuide：Scorpion identification / dorsal morphology](https://www.vapaguide.info/morphology/SCO-NORAM)：已读取背视结构说明；其原始图服务返回 403，未将该图冒称为已查看。
- [Icons8 14.0 Scorpion，Emojipedia](https://emojipedia.org/icons8/14.0/scorpion)：已通过原生图像工具查看实际插图，腹部末端与尾部独立、外侧轮廓清楚。

本轮明确造型约束：尾根保持腹部后端；尾杆向上抬起，尾梢继续向画面右外侧展开，远离头部与背甲。generation/outward_direction_guide.png 只用于向生成器说明方向，不是交付美术。

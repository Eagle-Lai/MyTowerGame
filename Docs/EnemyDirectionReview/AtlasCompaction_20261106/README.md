# 怪物方向图集紧凑排布（2026-11-06）

已处理 119 张方向图集，1622 个部件保留原始 RGBA 像素、切片尺寸、Pivot、PPU 与对外引用。最终使用按实际内容裁紧的非二次幂尺寸，保持 8px 间距与外围留边、4px 尺寸对齐，不旋转、不缩放、不复用重复像素。

全量 RGBA32 理论纹理数据：1900 MiB → 首轮 924 MiB → 最终 574.80 MiB；相对最初减少 69.75%，相对首轮再减少 37.79%。这不是游戏实际同时驻留的显存。

切片矩形总占用率 86.71%，各图范围 81.44%–94.09%；轮廓内部必要透明区域仍然保留。PNG 源文件总计 105.67 MiB → 104.90 MiB，包体与显存并非同一统计。

## 实施与验证

- 新增共享装箱模块 `.workbuddy/tools/directional_atlas_packing.py`，搜索多种宽高与矩形装箱顺序，按实际占用裁边。
- 新增 `.workbuddy/tools/compact_monster_direction_atlases.py`，提供 stage / apply / verify；改前保留基准，写入前核对散列，逐切片回读像素。
- 更新 Batch01_10 与 Remaining_20261024 的主生成脚本，使用同一装箱算法；未重新运行历史美术生成或单角色返修脚本。
- 两条 C# 方向图集导入链显式设置 `TextureImporterNPOTScale.None`，保留新图集实际尺寸。
- 图集、切片清单及其 meta 共 357 个资源文件；预制体、动画、布局、其他原画等 3247 个受保护文件散列未变。
- Monkey 的 5 个旧切片原 meta 的 internalID/nameFileIdTable 为 0，Unity 实际 ID 由导入器生成。已把改前实际 ID 显式保存，防止重排导致引用变化；对外 fileID 与原来一致。
- 原始基准与最终资源直接比对：1622 个部件 RGBA 字节完全一致。
- Unity MCP：按本次现场 8086 选定 MyTowerGame，核对工程路径与版本；强制刷新、编译、等待就绪后确认 `scriptCompilationFailed=false`。
- 从 Unity 实际加载的 119 个 RGBA32 纹理核对尺寸，与清单完全相同；1622 个 Sprite 的 GUID、fileID、宽高、像素支点和 PPU 与改前快照一致。
- Console 未清理：保留原有 APK 访问权限/构建错误；本次导入期间 Monkey 后台工作进程出现缩略图生成错误，主编辑器预览随后可正常生成。此项没有作为实机画面验收。
- 本轮未进入 Play Mode，也未重新打 APK；实战与真机视觉验收由用户完成。

## 1. 量纲

- 长度：格（cellSize = 1）；时间：秒（x1）；金币：整数。
- **HP 当量（HPE）**：怪物对防线的"消耗量" = `hp / (1 − armor)`，即无护甲等效血量。
- **火力**：`DPS = power / CD`；单体塔对单目标；范围塔对 k 个同时在爆炸半径内的地面目标为 `k × DPS`。
- **暴露时间** `τ`：一只怪处于某塔射程内的时长。地面 = 该塔覆盖的路径格数 / 实际速度；空中 = 飞行直线与射程圆的弦长 / 速度。
- **吞吐量** `Φ(t)`：参照解在时刻 t 对一只怪能造成的总伤害 = Σ_塔 DPS × τ（按目标分配后的有效值）。

## 2. 参照解（核心）

### 2.1 定义
对每关每波，参照解是一条**确定的建造时间线** `B = [(t_i, 动作_i)]`，满足：

1. **只增不减**：动作只有「在格 c 建 X 型 1 级」和「升级格 c 的塔」；
2. **现金可行**：任意时刻 `金币(t) = 100 + Σ已到账赏金 + Σ已到账波次奖励 − Σ已花费 ≥ 0`；
3. **终局阵型固定**：最终阵型 = 本关地图的**最长诱导路径**（所有非路径的可建格都建塔）+ 火力配置；中间每一步都是终局阵型的子集——这保证"不存在错误建造"；
4. **零漏怪**：按运行时规则模拟（四向 A*、即时命中、最远进度优先、对空优先、减速取最强不叠加），每波 0 漏；
5. **恰好吃掉**：每波的怪物总量被调到使**本波最紧的那只怪恰好在终点前死亡**（余量系数 `m = 剩余路程 / 总路程` 落在目标带内，见 §5）。

### 2.2 "最长绕路 + 最长火力覆盖"的构造
- **绕路**：每座塔既是墙也是火力。终局墙体 = 最长诱导路径以外的全部可建格。建造顺序按「每步使当前最短路增量最大」贪心排定，得到 **L(n)**：建了 n 座塔时的地面路径长度。
- **火力**：给定 n 座塔的位置，按「覆盖路径格数 × 单位金币 DPS」排序决定哪些格放输出塔、哪些格放减速塔、哪些升级。墙体格中**离路径最远**的格放最便宜的塔。
- **当波经济**：第 w 波开始时可用金币 + 本波波中赏金按时间到账，参照解在到账时刻立即执行下一个动作。

### 2.3 提前设防的严格判据
设第 w 波首只空中怪进入第一座单体塔射程的时刻为 `t_air`，参照解在此时必须拥有防空火力 `F_air`。若

```
造价(F_air) − 上波末结余 > Σ_{t < t_air} 本波已到账赏金
```

则该波为**必须提前设防波**：差额只能来自上一波结束时留存的金币或已提前建成的单体塔。参照解在上一波的时间线上会显式出现「留钱 / 预建单体塔」动作，设计稿逐波标注。

## 3. 难度刻度（横向比较 30 关、750 波）

关卡互相独立、每波都被参照解恰好吃掉，所以刻度衡量的是**参照解对玩家的要求有多紧**，不是"能否通过"。

`D(波) = 25·d1 + 25·d2 + 25·d3 + 25·d4`，满分 100：

| 分项 | 定义 | 归一 |
|---|---|---|
| d1 维度数 | 本波同时生效的压力维度数 / 5 | 0–1 |
| d2 预留比 | 提前设防所需预留金币 / 本波总可用金币 | 0–1 |
| d3 时序精度 | 1 − 关键动作「最晚可行时刻 − 最早可行时刻」/ 本波时长 | 0–1 |
| d4 余量紧度 | 1 − 本波最紧怪物的剩余路程比 m / m_max | 0–1 |

`D(关) = 25 波 D 的均值`，另报峰值波与困难波均值。难度曲线 = 30 个关点 + 750 个波点。所有分项都从参照解时间线上读出，可回溯。

## 4. 三型塔的不可替代性（设计目标）

| 塔 | 独占场景 | 可计量指标 |
|---|---|---|
| 单体（type 1） | **唯一的对空输出**；高护甲/高血精英的集火 | 对单目标 DPS/金币 最高 |
| 范围（type 2） | 地面集群：同时在爆炸半径内 k ≥ 2 只时效率反超单体 | 盈亏点 k* = (单体 DPS/金) / (范围 DPS/金) ≈ 2 |
| 减速（type 3） | 高速怪、空中短航程（唯一能拉长空中暴露时间的手段） | **等效增伤** ΔDPS = Σ_覆盖重叠的输出塔 DPS × s/(1−s)；价值 = ΔDPS / 造价，与输出塔 DPS/金币 同尺比较 |

参照解里减速塔出现的条件：`ΔDPS/造价 > 输出塔 DPS/金币`。全局参数按此保证：减速塔在**覆盖 ≥ 2 座输出塔的重叠区**才划算，单放无价值——这就是它"可计量"的价值。

## 5. 时长约束

```
T(关) = Σ_w [出怪跨度_w + 最后一只怪的存活时间_w] + 24 × 10 s ∈ [600, 900] s
```

- 24 × 10 s = 240 s 固定；25 波共享 360–660 s，**平均每波 14–26 s**。
- 存活时间由参照解的击杀点决定；路径越长、怪越慢，波越长。时长约束因此直接限制**地面速度下限**与**出怪间隔上限**。
- 困难波允许 1.5–2 倍普通波时长，其余普通波相应压缩。
- 每关验证记录附逐波时长表与总时长校验。

## 6. 五个战役阶段的压力维度

每阶段**新增**一个维度，后续阶段可组合使用前面的维度（但每关独立设计，不继承数值）。

| 阶段 | 关卡 | 新维度 | 主要逼出的塔 | 说明 |
|---|---|---|---|---|
| S1 | L01–06 | **基线**：地面流 + 零星空中 | 单体 | 空中只在困难波出现；建立绕路习惯 |
| S2 | L07–12 | **集群**：小血量高密度地面群 | 范围 | 出怪间隔压缩，k ≥ 3 |
| S3 | L13–18 | **高速**：速度 ≥ 1.8 倍基线的地面快怪 | 减速 | 不减速则暴露时间不足 |
| S4 | L19–24 | **装甲**：armor 0.3–0.5 的精英 | 单体 3 级集火 | 范围塔低伤被护甲吃掉 |
| S5 | L25–30 | **双峰**：地面峰值与空中峰值同波叠加 | 全部 + 提前设防 | 预留比最高 |

**空中压力**：由防空产能反推——每波空中 HPE 上限 = 参照解在 `t_air` 时刻买得到的单体火力 × 空中暴露时间。任何阶段都存在买得到的解；**每关至少 2 个困难波**设为必须提前设防波，阶段越后预留比越高（S1 ≈ 0.15 → S5 ≈ 0.45 的目标带）。空中怪出生仍遵守"空中怪不得相邻出生"。

## 10. V2.2 修订（2026-11-15，空中规则）

1. **W1–W4 无空中；W5 起每一波都有空中怪。**
2. **空中压力三档**（用户定）：
   - 轻压 = 空中怪占用航线单体对空产能 **20%**；中压 = **40%**；困难波 = **峰值**（空中先定上限，必须提前设防）。
   - 每 4 个普通波里中压个数随阶段递增：S1 1 → S2 1 → S3 2 → S4 2 → S5 3；优先给困难波前一波，其次 k=1、k=3 位置；其余为轻压。
   - 「产能」由模拟求出：只有空中、地面极弱时，参照解在余量线下能守住的空中血量上限；按档取比例后，地面再吃剩余火力。
3. **空中总血量以航线火力为依据**（用户要求）：
   - 航线火力位 = 空中航线 2.5 格内、不在终局地面路径上的可建格；参照解终局阵型把这些格全部建成单体并升到 3 级（减速/范围已占的格保留，减速塔延长空中暴露）。
   - 这些动作从预算中预留，出场顺序仍按单位金币增伤排序，所以空中火力随关卡推进逐步成长，空中血量随之增长。
   - 每波在设计稿中给出「航线火力」（波初已建覆盖航线的单体塔对一只飞过空中怪的最大伤害）与「空中/航线」比值，可直接复核。
4. 空中只数随航程缩放（航程/10，限 0.6–1.4 倍）：航程短的图空中只数少、单只血量高。
5. 经济：赏金按 3 位小数、金币按整数可用，收入多留 5 金取整余量，通关结余 ≤ 约 5 金；清波奖励向上取整。

## 11. V2.3 修订（2026-11-15，用户实测 L01 至 W20 后重做）

**问题**：V2.2 参照阵型把航线 2.5 格内的格全部建成 3 级单体，L01 航线贯穿全图，结果参照阵型几乎全是单体；困难波空中占总血 80%–99%、地面每只只剩 7–156 血，普通波空中只占 5%、地面每只 1,100+ 血。玩家按常见打法（单体 + 范围 + 减速混搭）时地面在第 5 列就清空，空中却漏怪，困难/普通波的落差也非常明显。

| 项 | V2.2 | V2.3 |
|---|---|---|
| 参照阵型 | 航线格全部 3 级单体 | **玩家常见打法**：绕路墙以单体为主；被路径两面包住的拐角放范围塔（S1 12% → S3+ 18% 的墙）；U 形掉头尖端放减速塔（5% → 8%）；升级预算 30% 给航线单体、70% 给地面火力，两池同步推进 |
| 空中强度 | 按对空产能 20% / 40% / 峰值 | 按**等效血量占比**：轻 25% / 中 35% / 困难 30%，W5 起每波都在 25%–35% |
| 困难波 | 空中峰值 + 必须提前设防 | 所需火力 **+15%**（同构成 + 1 只精英，W25 为首领，放在约 60% 位置）；**取消提前设防** |
| 怪数 | 每波 6–18 × 倍率 | **约 2.5 倍**：W1 15 只 → W25 52–87 只 |
| 速度 | 1.0–1.6 格/s | 1.0 / 1.08 / 1.15 / 1.22 / 1.3 格/s（重甲 0.8、精英 0.9、首领 0.8 倍） |
| 节奏 | 总战斗时间 900–1200 s | **单波 30–60 s**（每波标定后测时长，不在区间就调出怪跨度重标）；总时长不强制 |
| 空中出怪 | 困难波集中在开头 | 全程均匀穿插（仍不相邻、首尾为地面） |
| 余量 / 反应 | S1 30% → S5 15%；3 s | 不变 |

新增原型 **E 精英**：地面，血量 ×4、速度 ×0.9、护甲 0.15、漏怪扣 3，外观沿用本关 elite 行。难度刻度 d2 由「预留比」改为「空中占比 / 35%」。

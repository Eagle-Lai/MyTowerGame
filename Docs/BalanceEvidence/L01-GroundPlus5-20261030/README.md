# L01：W5 起地面怪数量 +5% —— 2026-10-30

## 需求

> 「第一关给波次，从第五波开始，地面怪物的数量都增加 5%。」

## 落地口径

- **只加地面**（`isFlying=0`），**空军一只不动**（保住"空军逐波递增"的设计）。
- 每波新增 = `round(该波地面数 × 0.05)`；新增个体按该波**现有地面变体占比**分配（最大余数法），
  成分不变、总数精确；再按均匀间隔插入序列，不堆在末尾。
- `LevelRating.expectedEnemyCount` 同步 +441；`planHash / balanceRevision` 更新。

## 三个值得注意的副作用

1. **相对增幅几乎没变**：因为 W19 和 W20 都 +5%，`W19→W20` 仍是 **+29.9%**（上一轮定的 +30% 保住了）。
2. **瞬时压力几乎不变**：怪多了 5%、波次也长了 5%（出怪间隔没改），所以 `EHP/秒` 基本持平
   （W20 1,961→1,955，W25 2,390→2,390）。实际体验是"这一波多打 5% 的怪、多花 5% 的时间"。
3. **W25 刚减的 20% 被抵掉一部分**：410,396 相对减血前的 491,049 是 **−16.4%**（不是 −20%）。
   如果要把终局维持在 −20%，W25 地面血量需要再乘 ~0.96。

经济：击杀金 2,733 → **2,839**（+106），总收入 3,788 → **3,894**。

## 【追加 2026-10-30 08:00】经济中性修正：怪 +5%，金币不涨

用户追加：「我只是说增加地面怪物 5%，不希望经济也增加 5%，你要重新计算。」

只加数量会让击杀金从 **2,733.00 涨到 2,839.16（+106.16）**，所以要按比例压低地面怪的单只奖励：

# L01 W20 压力波压平（EHP +68% → +30%，出怪间隔 −2.5%）—— 2026-10-29

## 需求（用户原话）

> 「调整这个波次，全波等效血量 EHP 总增幅控制在 30% 左右，而且出怪间隔改为 −2.5%，
> 然后从第二十一波到 25 波次的增幅都维持不变。」

## 落地口径

| 项 | 改前 | 改后 |
|---|---|---|
| W20 全波 EHP | 220,707.5 | **170,749.3** |
| W20 相对 W19 的 EHP 增幅 | **+68.0%** | **+30.0%**（精确） |
| W20 出怪间隔 | 147ms（相对 W19 的 154ms = −4.55%） | **150.15ms**（−2.50%） |
| W20 敌数 | 580 | 580（不变） |
| W20 击杀金 | 150.24 | 150.24（不变，奖励按角色不按血量） |
| 整关总收入 | 3667 | **3667（不变）** |
| W21–W25 | — | **一律不动**（数值、间隔、奖励全部原样） |

实现方式：W20 的 5 个变体 `hp` 统一乘 **k = 0.773645**（= 131,345.608 × 1.30 ÷ 220,707.533）。
因为 EHP 与 hp 严格线性、且 5 个角色的组成/护甲/数量都没动，缩放后 EHP 精确落在 +30.0%，
不需要逐角色重算权重。

```
5000190 Chicken  hp 253.842 -> 196.384
5000191 Larva    hp 164.998 -> 127.650
5000192 Crawler  hp 467.070 -> 361.346
5000193 Scarab   hp 863.064 -> 667.705
5000195 Bat      hp 541.531 -> 418.952
W20 enemyInterval 147 -> 150.15ms（= W19 的 154 × 0.975）
```

`enemyInterval` 在 Luban 里是 float、代码侧 `WaveConfig.SpawnIntervalMs` 也是 float，
所以 150.15 可以保留两位小数，不需要取整到 150ms（那会变成 −2.60%）。

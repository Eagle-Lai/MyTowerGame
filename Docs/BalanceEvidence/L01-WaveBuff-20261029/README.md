## 踩坑记录

- **写表工具必须防重入**：首次 --write 成功后，二次运行会把"已强化表"当基线再翻倍（已加
  波次敌数断言 + desc 标记双重护栏）。本次曾出现双重强化，用 `l01_design.py --write`
  （确定性生成器）精确恢复交付态后重新应用。
- 奖励预算分配是"每 +1 奖励 = +cnt2 金"，不能用逐金单位轮转（会爆出天价奖励），
  也不能按金单位贪心（无法精确命中）——最终用逐波 DP 完全背包（每变体 +1 上限 8）+ 全局
  ±1 局部搜索，残差 0。

# 30 × 25 长路线数值改造：用户补充规则

2026-10-19，用户明确选择：“优先长路线和火力复用，必要时允许低于 85% 占用”，并要求按此规则全面调整数值。

这是本次实施的用户指令，优先于输入 prompt 中以接近满铺为目标的默认实施指标。原 prompt 保留原文，旧密铺截图和结果作为历史对照保存。

## 布局与验收

1. 在真实四向寻路、占格和封路限制下，搜索实际 S→E 最短路线尽可能长的合法阵地。使用多次折返，使同一座塔能在敌人离开射程后再次攻击。报告搜索种子、预算、最好结果及上界，不将有限搜索写成全局最长路线的数学证明。
2. 留给敌人行走的格子服务于路线。不得为了占用率建设无实际输出、控制或阻断捷径作用的塔。对空单位保持直线飞行，需要单独设计拦截位置；仅与圆形射程相切不算有效射击窗口。
3. 原始可建格 B、容量 C 和 `ceil(0.85C)` 继续报告，分母不变。85% 是旧方案的比较指标，低于它不再自动判为失败。塔数与路线长度均不加入正式评分器。
4. 资金目标改为完成所选长路线和必要对空布防的实际一级施工费 `F_route`、实战必要升级 `U` 和调整损失。第 25 波开始前逐笔核实，不提前计入第 25 波收入。`F_C`（原容量下的 50/30/20 混合铺塔成本）保留为历史预算对照，不要求购买会破坏有效路线的剩余塔位。

## 联动数值

同时重调三类共九行塔的范围、攻击/控制、CD、增量价格与 AOE，敌群 EHP、数量、地空组成、速度与间隔，开场金、击杀奖励、清场奖励，以及八档梯度。先从真实余额建设长路线，再依照合法连续 25 波回放的出生跨度和清尾时间校准 Par。

继续保留普通主力、火力聚怪、减速混合、Ksmall、Klow、持续扩建和旧密铺的对照。失败和少塔反例完整记录；未实测组合标为预测，不能靠补无用塔或放宽评分条件宣布平衡完成。

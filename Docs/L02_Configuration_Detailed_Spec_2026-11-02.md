## 一、配置概览

### 1.1 地图对比分析

| 项目 | L01 | L02 | 比率 |
|------|-----|-----|------|
| 地图尺寸 | 13×7 = 91格 | 16×9 = 144格 | 1.582 |
| 可建造格 | 89格 | 142格 | 1.596 |
| 估算路径长度 | 14.8格 | 18.4格 | 1.243 |
| 初始金币 | 100 | 100 | 1.0 (不变) |
| 初始生命 | 10 | 12 | 1.2 |

**关键洞察**:
- L02地图更大，路径更长(+24.3%)，意味着怪物在路径上受伤时间更长
- 可建造格增加59.6%，玩家有更多塔位选择
- 为保持相同难度，怪物HP应适当降低以补偿路径增长

### 1.2 缩放策略

```
HP缩放因子 = 0.95
理由: 路径增长24.3% → 怪物受伤时间+24.3% → HP需降低约5%以维持相同击杀位置
```

### 1.3 ID映射方案

| 类型 | L01 ID范围 | L02 ID范围 | 转换规则 |
|------|-----------|-----------|---------|
| 波次ID (1-20) | 1-20 | 2001-2020 | +2000 |
| 波次ID (21-25) | 401-405 | 2401-2405 | +2000 |
| 敌人ID | 5000001+ | 6000001+ | +1000000 |
| 出怪列表ID | 1-20, 401-405 | 2001-2020, 2401-2405 | +2000 |

## 三、EnemyData.xlsx 配置

### 3.1 转换规则

对L01的每个敌人变体(106个):
1. **enemyId**: `5000001` → `6000001` (所有ID +1000000)
2. **hp**: 原值 × 0.95
3. **其他字段**: 保持不变(moveSpeed, armor, goldDrop, damageToPlayer, bodyRadius, isFlying, type, resName等)

## 四、EnemyList.xlsx 配置

### 4.1 转换规则

对L01的每个出怪列表(25个):
1. **id**: 加2000偏移 (1→2001, 401→2401)
2. **EnemyIndexs**: 字符串中每个敌人ID加1000000
   - 例: `"5000001,5000002,5000003"` → `"6000001,6000002,6000003"`
3. **其他字段**: interval, enemyInterval, desc 保持不变

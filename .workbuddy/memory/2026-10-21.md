**改动**
- `Assets/Scripts/Tower/BaseTower.cs`

  - `TickSlowAura` 注释补一条：光环**不参与**对空优先，禁止加"有飞行就跳过地面"的分支。
- `Assets/Scripts/Data/Persistence/AssemblyInfo.cs`：加 `InternalsVisibleTo("FTProject.BalanceCombat.EditModeTests")`（纯策略函数要能被 EditMode 直接验证；程序集特性写哪个文件都生效）。

- `Docs/GameDesign_自由人塔防_v3.md`：公共字段段补一条「索敌顺序（2026-10-21 定案）」。

## 层级/排序体检（地图 · 怪物 · 防御塔）— 只排查未改码

**基线（已核实）**
- `BoardSorting`（`Assets/Scripts/Game/Board.cs:162-174`）：Background -100 / Cell 0 / PathArrow 10 / RangeIndicator 100 / Enemy 200 / Tower 300 / Bullet 400 / Overlay 500。
- `ProjectSettings/GraphicsSettings.asset:40-41`：`m_TransparencySortMode: 3` + 轴 `(0,-1,0)`，Y 越小越靠前；`Main.unity` 相机未序列化该字段 → 未被相机覆盖，Y 排序真实生效。
- `TagManager.asset:42-60` 有 6 个排序层（Default/Bg/Main/Pop/Top/Over），**全工程非零 SortingLayerID = 0**，一个都没用上，全靠 Default + 数字 order。

**确认的问题**
1. **★ 31/119 敌人预制体 SortingGroup 序 ≠ 200**。根因 `MonsterPrefabBuilder.cs:129` `Object.Instantiate(source)` 直接克隆美术包，从未归一化组序（美术包自身组序 0/1/2/3/4、100–104、201–204）。`Board.cs:170` 注释「与怪物素材包默认值一致」对 31 个包不成立。
   - 0：Bear, BearMounted, BlackBear, MosquitoParasite, Panther, Pig, PossessedBlackBear, WinterBear｜1：BattlePanther, GreenParasite, Piggy｜2：IceParasite, Porky｜3：Swine, VolcanoParasite｜4：WildGoat｜100：FancyParasite, Goat, Lion｜101：MechanicalParasiteTypeA, Sheep, Tiger｜102：MechanicalParasiteTypeB, Ram｜103：Donkey｜104：Burro｜201：Ox｜202：Bull, BullMounted｜203：Pony｜204：Horse。
   - 组序 0–4（16 个）被格子(0)/箭头(10)/射程圈(100)压住；组序 0 的 8 个还与地砖同序（怪在格心时排序键相等 → 结果不确定）。100–104 永远被 200 组盖住；201–204 永远盖住所有怪。
   - 高频中招（tbenemydata.json 12705 条）：Pig 601 / GreenParasite 556 / Tiger 436 / Bull 393 / Bear 381。
2. **★ 血条 500/501 被 SortingGroup 钳制**：`MonsterPrefabBuilder.cs:322-333` HpBar 挂在带组的根下，子级 order 只在组内生效 → 全局仍是 200，塔(300)/子弹(400)盖住血条，与 `Overlay=500` 意图不符。119 个全中。
3. **塔无 SortingGroup**：9 个塔只有 barbette 300 + Img_gun 301。炮管恒压邻塔炮座，但实测重叠仅 0.012 格（1.28×0.8=1.024 vs 格 1.0）→ 结构性缺口，现症不可见。
4. **塔(300) 恒压怪(200)**：怪物高度中位数 1.33 格、最高 2.46（蝎子），怪走到塔下方格时头部被塔盖，与 Y 排序直觉相反。属设计取舍（`Board.cs:171`）。
5. 射程圈 100（`RangeIndicatorView.cs:58`）与减速光环 100（`SlowAuraView.cs:36`）同层同序 → 选中减速塔时两圈靠 Y 打架。
6. `BaseTower.cs:164-176` 把 <300 子渲染器一律抬到 300：现在只有炮座/炮管无影响，但以后给塔加影子/光环会被抬到 300 盖怪（SlowAura 因在 Init 后 Attach 才躲过）。

**判定口径**
- SortingGroup 的 order 决定整组全局位置，子级 500/501 **不能越出组**；200 vs 300/400 是硬优先级，只有同层同序才走 CustomAxis(0,-1,0)。

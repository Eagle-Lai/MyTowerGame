- 现状：工程本有完整快照（LevelSnapshot + snapshot_tower + LevelCheckpointValidator + TryRestoreSnapshot），**但 `IsCompatible` 用 versionKey（profileId|balanceRevision|ratingRevision|planHash）严格比对，且 `SaveManager.EnsureRatingVersion` 在版本变化时直接清空 `_data.snapshot`** —— 改表即作废，正好堵死这个场景。
- 方案：新增 `FailedRunCheckpoint`（`Assets/Scripts/Data/Persistence/FailedRunCheckpoint.cs`），落 **kv_store 明文键 `checkpoint/failed-run`**（不参与评级版本校验，改表/重启都不丢）。字段：levelId/completedWaves/failedWave/gold/hp/maxHp/双计时/塔列表(row,col,type,level)/configVersionKey(仅日志)。
- 写入点：`OnGameOver(false)` → `CaptureFailedRunCheckpoint()`；数据源是本波开始前 `OnStartRequest` 刚存的快照（正好是"失败这一波的开头"），快照缺失时退化为"当前塔阵 + 满血"。恢复点只到**波次边界**，不存半途怪物位置/血量。
- 恢复：`InitLevel` 先 `TryRestoreSnapshot`（原逻辑，返回 bool），失败才 `TryRestoreFailedRun`；`TryGetResumableCheckpoint` 增加兜底 → 主菜单"继续"、选关、关卡详情文案**零 UI 改动**自动生效。
- 清除：通关、`RestartLevel`、关卡详情"重玩"、切到别的关。
- **代价**：续局局 `statisticsValid/timingValid=false` + `debugOverride=true` → 不计星、不改写通关记录；`SaveSnapshotNow` 对这类局早退（否则退出时写出过不了校验的快照，下次进关先弹"快照不兼容"再弹"已续局"，自相矛盾）。
- 验证（Play Mode 端到端）：建 2 塔→开波→`LoseHp(99)` 强制失败→`cp=True 关卡1 死于第1波 金币100 生命10/10 塔2座`；退出重进后 cp 仍在；`ClearSnapshot(true)` 模拟改表后 `可续玩=True 关卡=1 下一波=1`；`StartLevel(1)` 恢复出 `[0,0 T1L1][0,2 T2L1] gold=100 hp=10/10 statsValid=False debugOverride=True`；运行期 0 error，`scriptCompilationFailed=false`。
- 未验：真机 Android；"半波恢复"未做（有意）。
- 文档：`Docs/FailedRunResume_2026-10-29.md`。

## 3 级普通塔对空伤害 +10%（新增 airDamageScale 列，已实测）

- 需求："3 级普通塔对空伤害 +10%，其余不变"。**不能直接改 power**（power 地空共用，改了两边都涨），所以新增**只对飞行生效**的倍率列。
- 表：`TowerInfo.xlsx` 末尾新增 `airDamageScale`（float），9 行显式填 1，仅 **id=3 Normal Lv3 填 1.1**。`power` 仍是 6/9/13… 未动。
- 代码：`TowerConfig.AirDamageScale`（>0 取值否则 1）+ `BaseTower.HurtEnemy` 里 `if (e.Config.IsFlying) damage *= Config.AirDamageScale`（放在伤害唯一入口，单体/AOE 共用）。
- **踩坑**：加列会改 `cfg.TowerInfo` 构造签名 → `Assets/Tests/BalanceCombat/CombatTargetingAndSlowTests.cs:197` 手工构造处报 `CS7036`，补第 20 参 `1f` 后通过。以后给单文件全局表加列，先 grep `new cfg.TowerInfo(`。
- 验证：hash **2a41a166…**（30 关重封）→ Play Mode `[Rating] verified 2a41a166…` 0 error；反射调 `HurtEnemy` 打 10 点：**空军扣 11（×1.1）/ 地面扣 10（不变）**；`power=13 airScale=1.1`。
- 影响面：TowerInfo 是全局表 → L01-L30 的 3 级普通塔对空全部 ×1.1；评级不读塔伤害，不影响星级口径，但会改变可打性。

# 2026-10-27

## 修复 AudioClip 预览报错（Unity Audio 被禁用）

- 现象：Inspector 里选 `Assets/Audio/OriginalPack_20261023/BGM/ft_bgm_battle.wav` 显示「AudioClip preview not available when Unity Audio is disabled in Project Settings」。
- 根因：`ProjectSettings/AudioManager.asset` 的 `m_DisableAudio: 1`，是 2026-10-23 无声版本提交 `ac1c4289` 时特意开启的（记录在 `Docs/AudioRemoval_Verification_2026-10-23.md` 第 17 行）。
- 处置：改回 `m_DisableAudio: 0`，并在该文档末尾追加「后续变更（2026-10-27）」说明。仅恢复音频引擎，不恢复任何声音代码（AudioManager/AudioCatalog 仍删、Boot 无 AudioListener、prefab 无 AudioSource），游戏运行时依旧无声。
- 坑：**Unity 正在运行工程时改 ProjectSettings/*.asset 不会立即生效**（内存里是旧值，且后续在 Project Settings 里任何改动都会用内存值回写覆盖文件）。要立刻生效必须在编辑器里 Edit > Project Settings > Audio 手动取消勾选「Disable Unity Audio」，或重开工程。本次 FisherTestGame（PID 47972，Unity 2022.3.62f3c1）就是这样处理的。
- 备注：本工程 8080 端口被 WorkBuddy 的 node 进程占用，不是 Unity MCP 桥；本会话无 unityMCP 工具，无法用 execute_code 改设置，只能改文件 + 让用户在 UI 确认。

### ★★四个必须记住的坑（都实际踩过）
1. **`ScreenCapture.CaptureScreenshotAsTexture()` 在 `EditorApplication.update` 里返回 null**（Console：`Was method called before the 'end of frame' state was reached?`）。
   → 必须改用 `CaptureScreenshot(path)` 异步落盘 + 编号 PNG 序列 + ffmpeg 合成。**不要再用 AsTexture 方案**。
2. **Unity 编辑器最小化时渲染目标只有 100×957**，但 `Screen.width/height` 仍报 1280×720（Console：`requested a region that exceeds the active Render Target sized [W:100, H:957]`）。
   → Begin 里用 `IsIconic` + `ShowWindow(hwnd, 4)`（SW_SHOWNOACTIVATE，恢复但不抢焦点）。窗口 rect 为 -32000 就是最小化标志。
3. **`Ready` 死锁**：验证器 `if (!Ready) return` 而不调 PushFrame，若 Ready 只在 PushFrame 里置位就永远为 false。
   → 必须由独立 `ProbeReady()` 在等待期间解析就绪状态。
4. **残留 `cancel.request` 导致下次开机即 cancelled**（原 `Finish` 不清理取消信号）。
   → `Finish` 收尾必须删除。

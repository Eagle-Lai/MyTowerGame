## git pull 失败排查（GitHub 连不上 / 502）
- 现象：`git pull` 报 `Failed to connect to github.com:443`；带"环境代理"重试变成 `CONNECT tunnel failed, response 502`。
- 根因：本会话注入的 `http_proxy/https_proxy = http://127.0.0.1:60044`（服务侧代理）不放行 github.com → 502；直连则完全不通。
- 解决：命令行显式覆盖为 Clash 混合端口
  `http_proxy=https_proxy=HTTP_PROXY=HTTPS_PROXY=http://127.0.0.1:7897 git -c http.version=HTTP/2 pull`
  （实测 7897、7892 均可出网；7897 为主）。
- 结果：Fast-forward `657c017` → `f3a747a`「UI 多分辨率适配 + HUD 暂停/菜单两按钮职责重划」，352 files / +56565 / -1172，工作区干净，HEAD == origin/main。

## 模拟器启动黑屏卡死修复（Build Settings 被改坏）[公司E]
- 现象：MuMu 里 freedomtower 启动后黑屏卡住（FPS≈1，仅背景），logcat 全是
  `The referenced script (FTProject.*) is missing` + serialization layout 错误，且无任何 `[Boot]` 日志。
- 根因：`ProjectSettings/EditorBuildSettings.asset` 在 `733ba00`（金色换皮提交）里被改成**只含 Main.unity 且启用**——
  Boot 场景被移出打包列表。APK 直接从 Main 空壳场景启动（热更脚本打包时被剔除）→ 全部脚本 missing → 黑屏。
  正确配置（ee973da）：Boot 启用 + Main 禁用（main 只能从 AB 加载）。
- 修复：恢复 EditorBuildSettings.asset 为 Boot(enabled)+Main(disabled)，经 MCP 菜单构建重出 APK（Builds/Android/freedomtower.apk）重装验证。
- ★教训：改 ProjectSettings 属于隐性破坏源；出 APK 前应核对 Build Settings 场景列表（Boot 启用、Main 禁用）。

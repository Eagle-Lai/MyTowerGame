## 通关阵型落盘 + 重进免费还原（已实施，编译通过）

需求原话：「每个关卡在关卡完成后，都保存当前关卡的防御塔摆放数据，进行落盘，游戏通关后再清除数据」。

**口径（用户两次确认，权威）**：
1. 保存的阵型用来 **重进已通关关卡时免费还原**（不是只记录）。
2. 「通关后清除」被收敛为 **每关通关时清旧写新**（同一关整条替换），不做全游戏通关后统一清空 ——
   因为"关卡完成后保存"和"最后一波完成后清除"是同一时刻，照字面等于存了立刻删。

**实现要点**：
- `Assets/Scripts/Data/LevelLayout.cs`（新增）：`TowerLayoutEntry{row,col,type,level}` /
  `LevelLayout` / `LevelLayoutBook` / `LevelLayoutStore`。整本阵型册存在 **kv_store 单键 `layout/campaign`**（`sensitive=true`），
  不建表、不改 schema（仍是 4），也不用 `level_snapshot`/`snapshot_tower`。
- 写：`GameFlowManager.CompleteVictory` 里 `RecordClear` 成功后才 `SaveCurrentLevel`；
  `RetryPendingClearSave` 补记一次。失败/退出/F2 调试胜利一律不写。
- 读：`InitLevel` 第 ⑦.5 步（`InitFromLevel` 之后）`LevelLayoutStore.Restore(levelId)`；
  走 `TowerManager.RestoreTower`（charge=false 不扣钱），批量期间抑制 `BuildTowerSuccess`、
  不逐座重算路径，`EndRestoreBatch` 统一 `RequestRefresh()` 一次 → 下一帧 `RefreshPathEvent` 重画箭头。
- `TryBuildInternal` 新增 `quiet` 参数：还原时**不弹 Tips、不刷红色高亮**（地图改过时的脏格不打断进关）。
- 某座塔摆不下 → 跳过并计数，日志 `[Layout] 第 N 关阵型已免费还原：X 座（跳过 Y 座）`。

**必须记住的经济防线**：免费还原 + 原价出售 = 刷金币。新增
`BaseTower.InvestedGold`（建造费/升级费记账，还原=0）与 `TowerManager.RefundOf`：
`返还 = min(配置售价, 实际投入) × Global.SellRefundRate`。
- 正常塔：投入≥售价 → 返还额与改造前**完全一致**（售价本就是累计投入约七成）；
- 还原塔 → 0；还原后升级 → 只返还升级费。
- 公式只允许一处：`TowerActionMenu` / `TowerInfoView` / `SellConfirmView` / `Sell` 全部改调 `RefundOf`；
  `SellConfirmView` 的"N% 累计投入"改为按该塔实算，避免"写 70%、到账 0"。

**验证**：`dotnet build` 四工程 0 error（`FTProject.Runtime` / `BalanceRating.EditModeTests` /

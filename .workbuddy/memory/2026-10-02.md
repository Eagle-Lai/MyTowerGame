### 踩坑记录（都靠 MSBuild 真编译当场抓出）

| 错误 | 原因 |
|---|---|
| CS1010 常量中有换行符 | 生成代码时把 TS 模板串的 `\n` 直接写进了 C# 字符串字面量，变成了真换行 |
| CS0111 Update 重复定义 | 加暂停热键时没注意 `GameFlowManager` 已有 `Update` |
| CS1031 应输入类型 | 修上一个问题时替换块少了一个 `{`，后续方法全变成"顶级语句" |

**仍然有效的方法**：`MSBuild Assembly-CSharp-Editor.csproj` 真编译 + 5 个 Python 静态校验脚本。
注意：**新增 .cs 后要手工往 csproj 补一行 `<Compile Include>`**，否则 MSBuild 看不到它
（csproj 是 Unity 生成的，在 Unity 刷新前不含新文件；它已被 gitignore，随便改）。

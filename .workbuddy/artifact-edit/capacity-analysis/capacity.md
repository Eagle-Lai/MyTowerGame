Source: `Assets/ConfigJson/tblevelmap.json` (2 maps). Generated by `.workbuddy/tools/balance_capacity.mjs` (no timestamp; identical input gives identical output).
Command: `node .workbuddy/tools/balance_capacity.mjs --levels 1,2 --spacing 2 --out D:\FreedomTower_1\.workbuddy\artifact-edit\capacity-analysis`

Rules (ported, see JSON `port`):
- Movement: 4-direction (AStarWrapper.cs GetSurroundPoints). Blocked: `#`, `X`, and tower cells. `S`/`E` are walkable.
- Route length: A* that stops when E enters the open list (balance_campaign._runtime_path). Edges = cells - 1.
- W = towers placed by snake_walls(augment=True): fingers + sentries. Each tower must keep S->E connected (BaseTower.cs TryBuildInternal).
- Capacity = buildable `.` cells minus the fewest `.` cells on any S->E route (balance_campaign.capacity).
- Euclid = straight-line start-end distance in cells.
